## Что вычисляет программа

В `main()` задаются исходные выражения `f`, `g` и переменные.
`solve_lagrange` самостоятельно составляет порядок действий метода:

1. Вычисляет градиент ограничения и ищет нерегулярные допустимые точки.
2. Строит функцию Лагранжа и все частные производные.
3. Решает полученную систему по координатам и множителю.
4. Проверяет подстановкой систему и исходное ограничение.
5. Строит Гессиан функции Лагранжа по исходным переменным и исследует
   квадратичную форму на касательном направлении к ограничению.
6. Вычисляет значения функции и сравнивает кандидатов.

Готовые координаты, производные и уравнение для множителя в решатель
не подставляются. SymPy выполняет символическое дифференцирование,
решение уравнений и упрощение; готовый оптимизатор не вызывается.

Реализация предназначена для двух переменных, одного равенства и конечного
списка изолированных действительных решений. При нерегулярных точках
или семействах решений выдаётся сообщение о необходимости отдельного
исследования. Автоматическая глобальная оптимизация произвольных функций
не заявляется: глобальность ответа для эллипса доказана в отчёте.

Глобальность следует из компактности эллипса и полноты списка кандидатов.
