## Условие

Нужно реализовать глобальный поиск экстремума липшицевой функции, заданной строкой, на отрезке с точностью eps. Показать исходную функцию, итоговую ломаную и найденную точку; вывести аргумент, значение функции, число итераций и время. Демонстрация должна иметь не менее двух локальных минимумов. Подмена метода поиском по мелкой сетке запрещена.

Для демонстрации выбрано сечение двумерной функции Растригина при y=0:

$$f(x)=x^2+10(1-\cos(2\pi x)),\qquad x\in[-2,2],\qquad \varepsilon=0.01.$$

Используется аналитическая оценка $L=4+20\pi$. На отрезке есть локальные минимумы по обе стороны от нуля; точный глобальный минимум $f(0)=0$.

## Результат

Получено $x_{\min}=0$, $f_{\min}=0$. Новых проб: 131; вычислений функции с учётом концов: 133. Итоговая нижняя оценка −0.0086279513, верхняя 0; разрыв 0.0086279513 < 0.01. Время локального запуска Kotlin — 0.004278 с, Python — 0.000501 с, зависит от среды; построение графика в него не входит.

`eps` ограничивает ошибку значения функции, а не расстояние по аргументу. Константа L оценивается по структуре выражения без сетки. Для неподдерживаемой автоматической оценки можно передать известное корректное L вручную. Проверка известных секущих не заменяет обоснование L на всём отрезке.

## Запуск основной версии Kotlin

Для запуска готового JAR нужна Java 17 или новее. Компилятор Kotlin не требуется:

```text
java -jar kotlin/lab02.jar
java -jar kotlin/lab02.jar "(x-0.37)**2" -1 2 0.01
java -jar kotlin/lab02.jar --self-test
```

Аргументы: строка функции, a, b, eps, необязательные `min|max`, `L|auto`, путь PNG. Без аргументов запускается демонстрация Растригина. Пример максимума:

```text
java -jar kotlin/lab02.jar "-(x-0.2)**2" -1 1 0.01 max auto maximum.png
```

Основной исходник: `kotlin/src/main/kotlin/Main.kt`. Для сборки есть Gradle-проект с Kotlin 2.4.21 и скрипт PowerShell:

```powershell
./kotlin/build.ps1 -Kotlinc "C:/path/to/kotlinc/bin/kotlinc.bat"
```

[Официальная инструкция по компилятору Kotlin](https://kotlinlang.org/docs/command-line.html).
Готовая программа не использует внешних библиотек: математика Kotlin, очередь Java и Java2D для PNG.
