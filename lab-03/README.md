# Лабораторная работа №3 — метод множителей Лагранжа

Борисюк Е. Г. Вариант 4.

Найти экстремумы $f(x,y)=xy$ при $x^2+4y^2=8$.

## Файлы

- [Отчёт PDF](report.pdf), [исходник LaTeX](report.tex).
- [Код Python](python/lagrange.py), [результат запуска](python/result.txt).

## Запуск

Из каталога lab-03, Python 3:

```text
python python/lagrange.py
```

Дополнительные пакеты не нужны. Используется только стандартный модуль math.

Программа вычисляет корни уравнения $16\lambda^2-1=0$, восстанавливает точки
из ограничения, проверяет невязки и сравнивает значения функции.
Ответ не записан в алгоритме заранее. Готовые оптимизаторы и поиск по сетке не используются.

## Результат

| Экстремум | Значение | Точки |
|---|---:|---|
| Глобальный максимум | 2 | (2, 1), (−2, −1) |
| Глобальный минимум | −2 | (2, −1), (−2, 1) |

Нерегулярных допустимых точек нет. При фактическом запуске получены все четыре
точки; максимальная абсолютная невязка системы в каждой равна нулю.
Ручное решение, обоснование полноты ответа и рефлективный вывод включены в PDF.

Исходник TeX содержит то же решение. Для сборки нужны pdfLaTeX, поддержка
русского языка, amsmath, amssymb, geometry и hyperref. Поставляемый PDF
сформирован программно; при отдельной сборке TeX разбиение страниц может отличаться.
