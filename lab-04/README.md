# Лабораторная работа №4 — динамическое программирование

Борисюк Е. Г. Вариант 4.

Распределение 7 серверных модулей между обработкой заказов, аналитикой и поиском.
Обработка заказов получает не менее 1 модуля; каждый сервис — не более 3.
Все модули распределяются полностью, значения целые.

## Запуск

Из каталога lab-04, Python 3:

```text
python python/dynamic_programming.py
```

Дополнительные пакеты не нужны. Класс `ResourceAllocation` самостоятельно
вычисляет таблицы Беллмана обратным проходом и восстанавливает все оптимальные
планы прямым проходом. Готовые оптимизаторы не используются.

## Результат

| Заказы | Аналитика | Поиск | Производительность |
|---:|---:|---:|---:|
| 1 | 3 | 3 | 31 |
| 2 | 3 | 2 | 31 |

Максимум равен **31**. Это все оптимальные распределения.
Результат и полный список планов проверены независимым перебором шести
допустимых распределений. Перебор служит только проверкой метода.

Отчёт содержит постановку, состояния и рекурсию Беллмана, полный табличный
расчёт, восстановление обеих стратегий, псевдокод, диаграмму класса,
результат программы и рефлективный вывод.

Исходник TeX содержит то же решение. Для сборки нужны pdfLaTeX, поддержка
русского языка, amsmath, amssymb, geometry, array и hyperref. PDF сформирован
программно; при сборке TeX разбиение страниц может отличаться.
